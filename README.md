# 📱 Mobile Store

A mobile-phone catalog web app — Listing, Detail and Cart views.

## ⚙️ The Stack

- Typescript
- React 19
- Node 24
- React Context
- Vitest
- Next.js
- CSS modules
- Playwright
- Prettier + Eslint
- Husky + Lint-staged
- Github actions
- Github pages
- Storybook

## 🧑‍💻 Dev setup

pnpm install
cp .env.example .env.local
pnpm dev
